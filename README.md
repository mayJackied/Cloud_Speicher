# Cloud Speicher

私人档案云盘。仓库公开，只作展示。

A private archival cloud drive. The repo is public as a showcase, not as a hosted service or a starter kit.

这不是对外开放的网盘服务，也不是相册站。没有公开注册；账号走邀请。本实例给自己用，源码放出来是为了能看见产品长什么样，不是把整条实现铺开当教程。

---

## 产品

每人一间私人目录，另有一块公共区。文件和文件夹是核心：上传、下载、重命名、移动、删除。界面是档案终端，不是通用后台模板。

- 网格 / 列表，右侧预览
- 图片蓝晒缩略图；GIF 与视频只抽一帧，网格里不播放
- 界面中文 / English / Deutsch；文件名按 UTF-8 原样保存，默认支持中日韩
- **Ctrl / Cmd 多选**；批量删除走 `deleteFiles`；移动暂仅单选
- 右键：**压缩**、**解压**（同名文件夹）、**解压到…**（可选父目录）；解压后会清掉 `__MACOSX`
- 侧栏新增**传输列表**：上传/下载统一入队，显示进度、速度、剩余时间并支持暂停、继续、取消、重试
- 传输任务用 IndexedDB 持久化；Edge/Chrome 可保存文件句柄，刷新后缺少权限时明确要求重新选择
- 侧栏**回收站**可进；最近 / 收藏 / 共享仍是占位
- 设置里有项目信息、语言、缩略图开关、删号

## 仓库里有什么

| 路径 | 说明 |
|------|------|
| `frontend/` | 浏览器里能看见的那一层 |
| `Api.md` | 前后端对接用，不是给路人接入的公开 API 说明 |

后端不在这个仓库里。字体文件按授权不能再分发，不入库。

想在本机打开前端壳：

```bash
cd frontend
npm install
npm run dev
```

没有配套服务的话，只能看界面，不能当真网盘用。
